Нативное приложение для macOS, которое создаёт PDF-книги из изображений и редактирует закладки PDF. Требования FreePic2Pdf реализованы заново с самостоятельно разработанным интерфейсом SwiftUI и системными фреймворками Apple. Сторонняя среда выполнения, загрузка файлов в сеть и настройка API-ключа не требуются.

## Использование

Скачайте `FolioPDF-1.3-macOS.zip` из [GitHub Releases](https://github.com/Uncas-X/FolioPDF/releases/latest), распакуйте архив и откройте `FolioPDF.app`. Приложение также можно перетащить в папку «Программы». Требуется **macOS 14 или новее**. Локально собранное приложение находится в `dist/FolioPDF.app`.

Пакеты версии 1.3 называются `FolioPDF-1.3-macOS.zip` и `FolioPDF-1.3-source.zip`; приложение внутри ZIP всегда называется `FolioPDF.app`. В [отчёте о проверке](../validation/VALIDATION.ru.md) указаны результаты, среда выполнения и снимки настоящего интерфейса. Репозиторий исходного кода не содержит кэшей сборки и бинарных файлов приложения; установочные пакеты доступны в Releases.

1. В разделе «Создать PDF» добавьте изображения, перетащите файлы или выберите одну либо несколько папок. Рекурсивный поиск по папкам настраивается справа до импорта.
2. Щёлкните изображение для выбора; Command-щелчок позволяет выбрать несколько. Перетащите изображение на другое, чтобы изменить порядок, или используйте нижние кнопки перемещения вперёд и назад. Двойной щелчок открывает просмотр. Можно переключаться между миниатюрами и списком.
3. Справа выберите единый PDF, отдельный PDF для каждого исходного файла или для каждой папки. Настройте бумагу, поля, DPI, сжатие, OCR и сведения о документе.
4. Для защиты паролем прокрутите правую панель вниз и раскройте «Шифрование PDF» после «Сведения о документе». Изначально раздел свёрнут; после раскрытия настройки видны прямо в панели. У параметров «Пароль для открытия» и «Пароль для редактирования» отдельные переключатели. Введите и подтвердите каждый включённый пароль; права описаны в таблице ниже. Эти настройки применяются ко всем PDF текущего пакета.
5. Нажмите «Создать PDF». Существующие файлы не перезаписываются: при совпадении имени автоматически создаётся новый файл с номером. Каждая страница или кадр многостраничного TIFF/GIF последовательно становится страницей PDF. Режим «Один PDF на файл изображения» не разбивает один исходный файл на несколько PDF.
6. В разделе «Закладки» можно открыть незашифрованный PDF, добавлять, редактировать, перемещать и изменять отступы пунктов оглавления, проверять переходы в просмотре, импортировать и экспортировать TXT, JSON или совместимые файлы интерфейса и сохранять копию.

Заголовки раскрывающихся разделов «Сведения о документе», «Шифрование PDF» и «Поля и разрешение» нажимаются по всей строке, включая пустое место рядом с текстом. Навигация по рабочим разделам слева также реагирует на щелчок по всей строке. «Шифрование PDF» изначально свёрнуто, а после раскрытия прокручивается вместе с правой панелью настроек.

⌘N показывает главное окно, ⌘O добавляет изображения, ⌘⇧O добавляет папки, ⌘E экспортирует, а ⌘, открывает настройки. Закрытие и повторное открытие главного окна сохраняет текущий сеанс. При выходе из приложения черновики закладок автоматически не сохраняются; предварительно сохраните копию.

### Пароли открытия и редактирования

| Включённый режим | Длина пароля | Права чтения и выполнения действий |
|---|---|---|
| Только пароль открытия | Открытие: 1–32 символа | Для открытия PDF нужен пароль; после ввода правильного пароля доступны все действия |
| Только пароль редактирования | Редактирование: 1–32 символа | Читать можно без пароля. Для обычного читателя ограничены изменение содержимого, аннотации, заполнение форм, вставка, удаление и поворот страниц. Пароль редактирования предоставляет все права |
| Оба пароля | Открытие: 1–16 символов; редактирование: 1–32 символа | Пароль открытия предоставляет ограниченные права читателя. Пароль редактирования даёт все права и также позволяет напрямую открыть PDF |

При включении обоих паролей они должны различаться. Печать, копирование и доступ для специальных возможностей остаются разрешёнными. Ограничения редактирования работают, если программа чтения PDF соблюдает права доступа; они не гарантируют абсолютную невозможность изменить содержимое.

Принимаются только печатные символы ASCII: латинские буквы без диакритики, цифры, знаки и пробелы. Действуют ограничения длины из таблицы. Если включены оба пароля, интерфейс сообщает о пределе 16 символов для пароля открытия. Слишком длинный ввод отклоняется до экспорта: пароли не обрезаются, начальные и конечные пробелы автоматически не удаляются.

Пароли хранятся только в текущем сеансе приложения и не записываются в настройки, историю или журналы. Отключение переключателя очищает соответствующий пароль и подтверждение; сброс настроек очищает обе группы. Недопустимый пароль или неверное подтверждение блокируют экспорт. Если оба переключателя отключены, создаётся обычный PDF.

По умолчанию язык интерфейса соответствует системному. В любой момент, без перезапуска, можно вручную выбрать один из этих **16 языков**:

Оформление может следовать системе, быть светлым или тёмным. Системные элементы macOS, например диалоги выбора файлов, используют язык системы. Язык интерфейса и язык OCR настраиваются отдельно; варианты OCR определяются возможностями Vision на этом Mac.

## Реализованные возможности

| Возможность | Реализация |
|---|---|
| Входные изображения | JPEG, PNG, TIFF, GIF, BMP, HEIC/HEIF, JPEG 2000 и другие форматы, декодируемые ImageIO; динамическое обнаружение дополнительных расширений, поддерживаемых системой. RAW зависит от локального системного декодера; поддержка всех моделей камер не гарантируется |
| Организация файлов | Удаление дубликатов, сортировка по имени или числу в конце, ручной порядок, распространённые префиксы электронных книг, рекурсивный обход папок и выбор включения верхней папки |
| Пакетный вывод | Единый PDF, PDF для каждого исходного файла или для каждой непосредственной родительской папки. Более глубокие папки группируются отдельно; их изображения повторно не учитываются в родительской папке |
| Страницы | Исходный размер, фиксированная ширина, A3/A4/A5/B5/Letter/Legal, собственные размеры в миллиметрах, альбомная ориентация, четыре поля, увеличение небольших изображений и приоритет метаданных DPI |
| Сжатие | Обработка без потерь и управление качеством JPEG. Для JPEG с нормальной исходной ориентацией может сохраняться исходный поток DCT. Другие форматы и ориентации корректно декодируются и размещаются через ImageIO; побайтовое сохранение потока каждого исходного формата не обещается |
| Прозрачность | Сохранение прозрачности или белая подложка. JPEG не хранит альфа-канал; при сохранении прозрачности автоматически применяется кодирование без потерь с поясняющим сообщением |
| OCR | Точное локальное распознавание Apple Vision, автоматический или ручной выбор доступного языка и скрытый текст, доступный для поиска и копирования. При сбое обработки на GPU выполняется попытка на CPU. Если распознавание страницы не удалось, её изображение сохраняется, а ошибка явно сообщается |
| Свойства документа | Заголовок, автор, тема и ключевые слова; одностраничный, непрерывный или двухстраничный режим чтения |
| Шифрование PDF | Нативный AES-128 PDFKit с паролем открытия, редактирования или обоими. При одном пароле открытия создаётся случайный пароль owner; заданный пароль редактирования предоставляет полные права owner. Файл публикуется только после проверки блокировки, паролей, прав reader/owner и числа страниц для выбранного режима. При ошибке незашифрованная замена не создаётся. Встроенный просмотр поддерживает ввод пароля |
| Закладки | Автоматические закладки исходных файлов, многоуровневое оглавление, номера страниц, пересчёт базовой страницы, редактируемый текст и JSON, нативный просмотр переходов PDF |
| Совместимость интерфейса | `FreePic2Pdf.itf` и `FreePic2Pdf_bkmk.txt`, UTF-8/UTF-16LE и соответствующие прежние кодировки; отдельная нумерация оглавления и основного текста, метаданные, добавление страниц с текстовым поиском и настройки показа закладок |
| Надёжность | Фоновые задачи, освобождение изображений по страницам, прогресс, отмена, журналы, временные файлы и атомарная публикация, нумерация при совпадении имён, сохранение и перечисление готовых результатов при сбое внутри пакета |

### Явные отличия от исходной программы

- OCR использует Apple Vision вместо MODI, не требует Office или Windows и не повторяет прежнюю очистку диаграмм, шрифты CJK или переключатели обработки по словам и строкам.
- Сейчас доступны сжатие без потерь и JPEG; кодировщики JBIG2, CCITT G4 и JPEG 2000 не воспроизведены. Основные функции работают, но объём крупных чёрно-белых книг может быть больше, чем у специализированных инструментов JBIG2.
- Нет прежних инструментов проверки для показа/скрытия OCR-текста или физического удаления сканированных изображений. Также нет восстановления изображений и полноценного редактора содержимого PDF.
- Многослойная сборка `[Images]` и `MinWidth` совместимого интерфейса пока не реализованы. При обнаружении выводится пояснение без утверждения, что настройки применены. Если ручной порядок файлов не совпадает с абсолютными страницами интерфейса, пользователь должен проверить переходы оглавления.
- Поддерживаются обычные локальные страницы, некоторые стандартные именованные действия и URL. Внешние PDF-цели, которые PDFKit не способен надёжно сохранить, и неразрешимые именованные или специальные цели явно помечаются и препятствуют незаметному сохранению. В редакторе их можно заменить допустимыми локальными страницами. JSON/TXT могут сохранять данные целей. Редактирование закладок зашифрованных PDF недоступно.
- При шифровании сохраняются закладки, OCR-текст, метаданные, режим чтения и обычная секционная нумерация. Нативный PDFKit не сохраняет метки страниц; приложение безопасно восстанавливает только метки без текстовых префиксов. Файлы интерфейса с пользовательскими текстовыми префиксами явно блокируют зашифрованный экспорт: удалите префиксы или отключите шифрование.
- Порядок электронных книг использует распространённые группы префиксов cov, bok, leg, fow, !, toc, числовой основной текст, att, ins, bac; остальные идут следом. Полное совпадение с неопубликованными правилами исходной программы не заявляется.
- При отмене или ошибке уже созданные PDF пакета сохраняются, а текущий незавершённый временный PDF удаляется. Возобновление с точки остановки не поддерживается.

## Разработка и сборка

Исходники оформлены как Swift Package; откройте `Package.swift` в Xcode. Нужны Xcode с macOS SDK и Swift 5.9 или новее. Проверенная среда — macOS 15.7.9 / Xcode Swift 6.2.4; целевая совместимость начинается с macOS 14.

```sh
# Запуск в режиме отладки
swift run FolioPDF

# Тесты и проверка текстов на 16 языках
bash scripts/test.sh

# Универсальная .app и ZIP для Intel + Apple Silicon
bash scripts/build-app.sh

# Сборка только для архитектуры текущего компьютера
bash scripts/build-app.sh --host-only
```

Реальные OCR-тесты в `scripts/test.sh` требуют обычного доступа к системным службам macOS, включая Vision и CoreVideo. В песочнице, ограничивающей оборудование или системные службы, создание CVPixelBuffer может завершиться ошибкой. В нормальной среде тесты должны выполняться и проходить; пропуск не заменяет проверку.

Для пакетов используется локальная подпись ad-hoc без нотаризации Developer ID. Их можно запускать локально; официальное распространение на другие Mac требует сертификата разработчика и процедуры нотаризации.

### Структура кода

```text
Sources/FolioCore/       Изображения, геометрия, конвертация, OCR, закладки и файлы интерфейса
Sources/FolioPDF/        Области SwiftUI, состояние, нативный просмотр и языки
Tests/FolioCoreTests/    Реальные циклические и граничные тесты изображений/PDF/OCR/закладок
scripts/                Тесты, упаковка, значок и генерация примеров изображений
packaging/Info.plist     Сведения о приложении macOS
docs/                   Отчёты о проверке и рендеринг настоящих окон
dist/                   Исполняемая .app и ZIP для распространения (создаются при сборке)
```

## Техническая основа

Используются Apple [API определения языка Vision](https://developer.apple.com/documentation/vision/vnrecognizetextrequest/automaticallydetectslanguage), [атрибуты документов PDFKit](https://developer.apple.com/documentation/pdfkit/pdfdocument/documentattributes) и [параметр качества JPEG ImageIO](https://developer.apple.com/documentation/imageio/kcgimagedestinationlossycompressionquality). Реализация дополнительно проверяется по объявлениям локального SDK и тестами реальных файлов. Исходная программа FreePic2Pdf, её значки и старый интерфейс не копировались.
