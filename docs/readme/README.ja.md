画像から本を作成し、PDF のブックマークを編集するネイティブ macOS アプリです。FolioPDF は独自に設計した SwiftUI の画面と Apple のシステムフレームワークを使用しています。サードパーティーのランタイム、ネットワークへのアップロード、API Key の設定は不要です。

## 使い方

[GitHub Releases](https://github.com/Uncas-X/FolioPDF/releases/latest) から `FolioPDF-1.4-macOS.zip` をダウンロードし、展開して `FolioPDF.app` を開いてください。「アプリケーション」フォルダにドラッグすることもできます。必要な OS は **macOS 14 以降**です。ローカルでビルドしたアプリは `dist/FolioPDF.app` に生成されます。

バージョン 1.4 の配布ファイルは `FolioPDF-1.4-macOS.zip` と `FolioPDF-1.4-source.zip` です。ZIP 内のアプリ名は常に `FolioPDF.app` です。[検証記録](../validation/VALIDATION.ja.md)に、検証状況、実行環境、実際の画面のスクリーンショットを掲載しています。ソースリポジトリにはビルドキャッシュやアプリのバイナリを含めず、インストール用パッケージは Releases で提供します。

1. 「PDF を作成」で画像を追加するか、ファイルをドラッグするか、1 つ以上のフォルダを追加します。フォルダを再帰的に読み込む設定は右側の設定パネルにあり、読み込み前に選択してください。
2. 画像をクリックして選択し、Command を押しながらクリックすると複数選択できます。別の画像の上にドラッグして並べ替えるか、下部の前へ／後ろへ移動するボタンを使用します。画像をダブルクリックするとプレビューできます。サムネイル表示とリスト表示を切り替えられます。
3. 右側で、1 つの PDF に結合、元ファイルごと、フォルダごとの出力を選び、用紙、余白、DPI、圧縮、OCR、書類の情報を調整します。
4. パスワードで保護する場合は、右側の設定パネルを下にスクロールし、「書類の情報」の後にある「PDF 暗号化」を展開します。このセクションは初期状態では折りたたまれており、展開すると設定がその場に表示されます。「開くためのパスワード」と「編集用パスワード」には個別のスイッチがあります。有効にした項目のパスワードと確認用パスワードを入力してください。権限の詳細は下表のとおりです。一括出力するすべての PDF に、その回の設定が適用されます。
5. 「PDF を作成」をクリックします。既存の出力ファイルは上書きせず、名前が重複する場合は番号付きの新しいファイルを作成します。複数ページの TIFF/GIF は、各ページ／フレームを順に PDF のページへ変換します。「画像ファイルごとに PDF を作成」では、1 つの元ファイルを複数の PDF に分割しません。
6. 「しおり」ワークスペースでは、暗号化されていない PDF を開き、目次項目の追加、編集、移動、インデント、移動先のプレビュー、TXT・JSON・互換インターフェースファイルの読み込み／書き出しを行い、最後にコピーとして保存できます。

「書類の情報」「PDF 暗号化」「余白と解像度」などの折りたたみセクションは、見出し横の空白を含む行全体をクリックできます。左側のワークスペース切り替えも行全体をクリックできます。「PDF 暗号化」は初期状態では折りたたまれ、展開後は右側の設定パネルと一緒にスクロールします。

⌘N でメインウインドウを表示し、⌘O で画像を追加、⌘⇧O でフォルダを追加、⌘E で書き出し、⌘, で設定を開きます。メインウインドウを閉じて再度開いても、現在のセッションは保持されます。アプリの終了時にブックマークの下書きは自動保存されないため、先にコピーとして保存してください。

### 開くためのパスワードと編集用パスワード

| 有効にする保護 | パスワードの長さ | 閲覧と操作の権限 |
|---|---|---|
| 開くためのパスワードのみ | 開くためのパスワードは 1–32 文字 | PDF を開くときにパスワードが必要です。正しいパスワードで開くと、すべての操作が許可されます |
| 編集用パスワードのみ | 編集用パスワードは 1–32 文字 | パスワードなしで閲覧できます。通常の閲覧者による内容の変更、注釈、フォーム入力、ページの挿入／削除／回転は制限されます。編集用パスワードを入力すると、すべての権限を取得できます |
| 両方のパスワード | 開くためのパスワードは 1–16 文字、編集用パスワードは 1–32 文字 | 開くためのパスワードでは制限付きの閲覧権限を取得します。編集用パスワードではすべての権限を取得し、そのパスワードだけで PDF を直接開くこともできます |

両方を有効にする場合、2 つのパスワードは異なるものにする必要があります。印刷、コピー、アクセシビリティのためのアクセスは常に許可されます。編集制限は PDF リーダーが権限設定を尊重することを前提としており、内容を絶対に変更できないことを保証するものではありません。

使用できるのは印字可能な ASCII 文字（英字、数字、記号、スペース）のみで、長さは上表の範囲に制限されます。両方のパスワードを有効にすると、開くためのパスワードの上限が 16 文字であることを画面に表示します。範囲外のパスワードは書き出し前に拒否し、切り詰めや先頭・末尾のスペースの自動削除は行いません。

パスワードは現在のアプリセッションにだけ保持し、設定、履歴、ログには書き込みません。片方のスイッチをオフにすると、そのパスワードと確認値を消去し、設定のリセットでは両方を消去します。パスワードや確認値が無効な場合は書き出しを禁止します。両方のスイッチをオフにすると、通常の PDF を書き出します。

設定画面の表示言語は初期状態ではシステムに従います。再起動せず、いつでも次の **16 言語**に手動で切り替えられます。

**简体中文** · English · 繁體中文 · 日本語 · 한국어 · Français · Deutsch · Español · Italiano · Português (Brasil) · Русский · العربية · हिन्दी · Türkçe · Nederlands · Polski

アラビア語では右から左への画面レイアウトを使用します。画像と PDF の内容は変更せず、ブックマークの TAB 区切りテキストエディターは左から右への構造を維持します。外観はシステム設定、ライト、ダークから選べます。システムのファイル選択画面など、macOS のコントロールはシステムで設定した言語を使用します。画面言語と OCR の認識言語は別々に設定し、選択できる OCR 言語はその Mac の Vision が対応する範囲で決まります。

## 実装範囲

| 機能 | 実装内容 |
|---|---|
| 画像の入力 | JPEG、PNG、TIFF、GIF、BMP、HEIC/HEIF、JPEG 2000、JPEG XL（`.jxl`）など、ImageIO でデコードできる形式。JPEG XL には macOS 14 以降のネイティブ ImageIO デコードを使用します。現在のシステムが対応する追加の拡張子も動的に検出します。RAW への対応はシステムのデコーダーに依存し、すべてのカメラ機種を保証しません |
| ファイルの整理 | 重複除去、ファイル名／末尾の数字による並べ替え、手動順序、一般的な電子書籍の接頭辞による並べ替え、フォルダの再帰読み込み、最上位フォルダを含めるかどうかの選択 |
| 一括出力 | 1 つの PDF に結合、元ファイルごとに 1 PDF、直近の親フォルダごとに 1 PDF。深い階層のフォルダは別のグループにし、子孫フォルダの画像を親フォルダに重複計上しません |
| ページ | 元画像のサイズ、固定幅、A3/A4/A5/B5/Letter/Legal、ミリメートル単位のカスタムサイズ、横向き、四辺の余白、小さい画像の拡大、画像の DPI メタデータの優先 |
| 圧縮 | 可逆圧縮と JPEG の品質調整。元の向きが正立の JPEG は、元の DCT エンコードストリームを保持できます。その他の形式や向きは ImageIO で正しくデコードして配置し、すべての元形式でストリームがバイト単位で一致することは保証しません |
| 透明度 | 透明度の維持、または白い背景。JPEG は Alpha を保存できないため、透明度を維持する場合は自動的に可逆圧縮を使用し、その理由を報告します |
| OCR | Apple Vision によるローカルの高精度認識。利用可能な言語を自動または手動で選び、検索・コピーできる非表示テキストを生成します。GPU 処理が失敗した場合は CPU を試します。認識に失敗したページは画像を残し、明示的に報告します |
| 文書の属性 | タイトル、作成者、件名、キーワード、単一ページ／連続／見開きの閲覧レイアウト |
| PDF の暗号化 | ネイティブ PDFKit の AES-128。開くためのパスワードのみ、編集用パスワードのみ、両方のモードに対応します。開くためのパスワードのみの場合はランダムな owner パスワードを生成し、編集用パスワードを設定した場合はそれで owner の全権限を付与します。モードに応じてロック状態、パスワード、reader/owner 権限、ページ数を検証した後にだけ出力を公開します。失敗時に非暗号化ファイルへ置き換えることはありません。アプリ内プレビューではパスワードを入力できます |
| ブックマーク | 元ファイルからの自動ブックマーク、階層化された目次、ページ番号、基準ページの換算、編集可能なテキストと JSON、ネイティブ PDF による移動先プレビュー |
| ブックマークのインターフェースファイル | 汎用の ITF（`.itf`）および `TXT` ブックマークインターフェースファイル、UTF-8/UTF-16LE と関連する従来の文字コード、目次／本文の区間別ページ番号、メタデータ、検索可能なテキストページの追加、ブックマークの表示設定 |
| 安定性 | バックグラウンド処理、ページごとの画像の解放、進捗、キャンセル、ログ、一時ファイルとアトミックな公開、同名時の自動採番、バッチ途中の失敗時に完了済みの結果を保持して一覧表示 |

JPEG XL は、非可逆圧縮、可逆圧縮、透明度付き、16 ビットグレースケールの静止画像の読み込み、サムネイル作成、プレビュー、PDF 変換に対応しています。アニメーション JXL で保証するのはシステムがデコードできる最初のフレームのみで、全フレームの読み込みは保証しません。現在の検証環境の ImageIO は最初のフレームだけを返します。JXL 形式へのエンコード出力は提供せず、元の JXL ビットストリーム、HDR、高ビット深度情報が PDF 内にそのまま保持されることも保証しません。

### 現在の制限

- OCR はローカルの Apple Vision を使用し、Office や Windows は不要です。図表除去、専用の CJK フォント設定、文字単位／行単位のスイッチは提供していません。
- 現在の圧縮方式は可逆圧縮と JPEG です。JBIG2、CCITT G4、JPEG 2000 のエンコードには対応していません。基本的な処理は利用できますが、大きな白黒書籍では専用の JBIG2 ツールより出力サイズが大きくなる場合があります。
- OCR テキストの表示／非表示やスキャン画像の物理削除を行う校正ツールは提供していません。画像の修復機能や、完全な PDF コンテンツエディターも含みません。
- 互換インターフェースの `[Images]` による多層画像の組み立てと `MinWidth` は未実装です。検出時には説明を表示し、適用済みとは扱いません。手動のファイル順序がインターフェースの絶対ページ番号と異なる場合は、利用者が目次の移動先を確認してください。
- 通常の文書内ページ番号、一部の標準の名前付きアクション、URL の移動先に対応します。PDFKit が安定して保存できない外部 PDF の移動先や、解決できない名前付き／特殊な移動先は明示的に表示し、問題を黙って無視して保存することを防ぎます。エディターで有効な文書内ページ番号へ変更できます。JSON/TXT は移動先データを保持できます。暗号化された PDF のブックマーク編集には対応しません。
- 暗号化ではブックマーク、OCR テキスト、メタデータ、閲覧レイアウト、通常の区間別ページ番号を保持します。ネイティブ PDFKit はページラベルを保持しないため、本アプリが安全に復元できるのは文字の接頭辞を含まないラベルだけです。独自の文字接頭辞を含むインターフェースファイルでは暗号化出力を明示的に禁止します。接頭辞を削除するか、暗号化をオフにしてください。
- 「電子書籍順」は、cov、bok、leg、fow、!、toc、数字の本文、att、ins、bac という一般的な接頭辞グループを使用し、その他を後ろに配置します。
- キャンセルやエラー時も、そのバッチで作成済みの PDF は保持し、処理途中の一時 PDF は削除します。中断箇所からの再開には対応しません。

## 開発とビルド

ソースコードは Swift Package です。Xcode で `Package.swift` を開いてください。macOS SDK を含む Xcode と Swift 5.9 以降が必要です。検証環境は macOS 15.7.9 / Xcode Swift 6.2.4、デプロイ先の互換性ターゲットは macOS 14 です。

```sh
# デバッグ実行
swift run FolioPDF

# テストと 16 言語の文言チェック
bash scripts/test.sh

# Intel + Apple Silicon のユニバーサル .app と ZIP をビルド
bash scripts/build-app.sh

# 現在のマシンのアーキテクチャだけをビルド
bash scripts/build-app.sh --host-only
```

`scripts/test.sh` の実際の OCR テストには、macOS の Vision、CoreVideo などのシステムサービスへの通常のアクセスが必要です。ハードウェアやシステムサービスを制限する実行サンドボックスでは、CVPixelBuffer の作成が失敗する場合があります。通常のシステム環境でテストを実行して合格することが必要で、スキップを検証の代わりにはしません。

パッケージにはローカルの ad-hoc 署名を使用し、Developer ID による公証は含みません。ローカルで実行できますが、他の Mac へ正式に配布する際は、開発者証明書と公証の手続きが必要です。

### コードの構成

```text
Sources/FolioCore/       画像、ジオメトリ、変換、OCR、ブックマーク、インターフェースファイル
Sources/FolioPDF/        SwiftUI ワークスペース、状態管理、ネイティブプレビュー、多言語対応
Tests/FolioCoreTests/    実際の画像/PDF/OCR/ブックマークの往復変換と境界テスト
scripts/                テスト、パッケージ化、アイコンとサンプル画像の生成
packaging/Info.plist     macOS アプリの情報
docs/                   検証記録と実際のウインドウのレンダリング
dist/                   実行可能な .app と配布 ZIP（ビルド時に生成）
```

## ドキュメントの言語

README と検証記録は、画面と同じ 16 言語で提供します。各文書の先頭にある言語リンクで切り替えられます。機能、パスワードの制限、既知の制限、ビルド手順は、どの言語版でも同じ内容です。テスト、ビルド、画面キャプチャのログはツールが生成した一次資料として元の出力を保持し、その説明を検証記録で多言語化しています。

## 技術的な根拠

Apple の [Vision の言語検出 API](https://developer.apple.com/documentation/vision/vnrecognizetextrequest/automaticallydetectslanguage)、[PDFKit の文書属性](https://developer.apple.com/documentation/pdfkit/pdfdocument/documentattributes)、[ImageIO の JPEG 品質パラメーター](https://developer.apple.com/documentation/imageio/kcgimagedestinationlossycompressionquality)を使用し、ローカル SDK の宣言と実際のファイルテストでも実装を検証しています。FolioPDF は独自の画面設計とネイティブのシステムフレームワークを組み合わせています。
