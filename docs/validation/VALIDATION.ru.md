Статус: **тесты и сборка прошли успешно**. Дата: 2026-10-23. Среда проверки: Intel Mac, macOS 15.7.9, Swift 6.2.4 / Xcode. Минимальная целевая версия: macOS 14.

В этой версии добавлены независимые пароли открытия и редактирования. Настройки шифрования находятся справа в изначально свёрнутом разделе, заголовок которого нажимается по всей строке. Выполнены все 50 XCTest: 0 ошибок, 0 пропусков. Подтверждено, что нативный интерфейс записи PDF на этом Mac может сделать пароль owner недействительным при длине пароля открытия 17–31 символ. Приложение обходит проблему проверкой длины до экспорта с двумя паролями; безопасные границы описаны ниже. Журнал этой проверки — `test-results.txt`.

## Поставляемые файлы

- `dist/FolioPDF.app`: нативные окна AppKit, интерфейс SwiftUI и системные PDFKit / Vision / ImageIO. Имя файла приложения не содержит версии; она записана в метаданных.
- `dist/FolioPDF-1.3-macOS.zip`: универсальное приложение с x86_64 и arm64, проверенное через `lipo -archs`.
- `dist/FolioPDF-1.3-source.zip`: исходники Swift Package для Xcode с тестами, скриптами, инструкцией и снимками интерфейса.
- Скрипт упаковки использует локальную подпись ad-hoc; `codesign --verify --deep --strict` прошёл успешно. Нотаризация Developer ID не выполнена. Внутренняя версия — 1.3 (build 4), имя файла остаётся `FolioPDF.app`.

### Критерии приёмки двух паролей

| Режим | Обычный читатель | Владелец пароля редактирования |
|---|---|---|
| Только открытие | Пустой или неверный пароль не открывает файл; правильный разрешает все действия | Отдельный пароль редактирования не задан |
| Только редактирование | Чтение без пароля; запрещены изменение содержимого, аннотации, заполнение форм и организация страниц | Пароль редактирования даёт полные права owner |
| Оба пароля | Пароль открытия даёт ограниченные права user | Пароль редактирования напрямую открывает файл и даёт полные права owner |

Пароли должны различаться. Во всех трёх режимах разрешены печать, копирование и доступ для специальных возможностей. Ограниченный режим отключает изменение содержимого, аннотации, формы, вставку, удаление и поворот страниц. Программа чтения должна соблюдать права; абсолютная невозможность изменения не гарантируется.

Допустимы только печатные символы ASCII. Безопасные пределы: только открытие — 1–32 символа; только редактирование — 1–32; два пароля — открытие 1–16 и редактирование 1–32. Условное ограничение явно показано в интерфейсе и проверяется до экспорта. Выход за границы вызывает ошибку без обрезки пароля, изменения крайних пробелов или ослабления защиты результата.

Для уже открытого PDF вызов `unlock(withPassword:)` может вернуть `true` даже с неверным паролем owner. Поэтому приёмка проверяет `permissionsStatus` и все биты прав: ограниченный reader — user/51, owner — owner/255, reader в режиме только открытия — user/255. Файл с одним паролем редактирования открывается автоматически; для чтения числа страниц в историю разблокировка owner не нужна.

## Интерфейс и языки

- Ресурсы содержат 292 текста × 16 языков, фактически в интерфейсе используется 281 текст. `check-localization.py` прошёл; языковые ресурсы пакета побайтово совпадают с исходниками.
- По умолчанию используется системный язык. Порядок соответствует запросу: 简体中文, English, 繁體中文, 日本語, 한국어, Français, Deutsch, Español, Italiano, Português (Brasil), Русский, العربية, हिन्दी, Türkçe, Nederlands, Polski.
- Главное окно и настройки используют RTL для арабского. Имена файлов, изображения и PDF не изменяются. TAB-редактор закладок сохраняет LTR, чтобы не менять смысл редактирования файлов интерфейса.
- Приложение было запущено заново, выполнен рендеринг его настоящего NSView. Проверены китайский светлый интерфейс со свёрнутым разделом и раскрытыми двумя паролями, немецкий тёмный с длинными текстами, арабский RTL и режим только редактирования. Поля и пояснения корректно переносятся; наложений и пропущенных символов не обнаружено. Выходящее за пределы окна содержимое прокручивается с правой панелью. Снимки приведены ниже.
- Заголовки «Сведения о документе», «Шифрование PDF» и «Поля и разрешение» используют Button на всю строку. Метка занимает доступную ширину, затем прямоугольник определяет область щелчка. Области навигации слева и нижнего входа в настройки также расширены. Проверка кода охватила пустые участки и семантические направления RTL; отдельной автоматизации мыши не выполнялось. Подтверждены запуск итогового приложения и повторное открытие главного окна; журнал содержит `reopen verified: true`.
- Во время конвертации закрытие окна и выход запрещены. При несохранённых закладках закрытие или выход требуют подтверждения. После повторного открытия сохраняется черновик сеанса.
- Кнопка настроек и ⌘, открывают одно нативное окно. ⌘N показывает главное окно, ⌘O добавляет изображения, ⌘⇧O — папки, ⌘E экспортирует.
- «Шифрование PDF» — отдельный раздел после «Сведения о документе» справа, изначально свёрнутый и прокручиваемый вместе с панелью. Раскрытие сразу показывает обе группы без всплывающей панели. Для каждой предусмотрены отдельный переключатель, скрытое поле пароля и подтверждение.
- Отключение группы очищает только её пароль и подтверждение; сброс очищает обе. Недопустимые пароли, несовпадающие подтверждения или одинаковые пароли блокируют экспорт. Если обе группы отключены, создаётся обычный PDF. Сворачивание и раскрытие не меняют защиту.
- Оба пароля существуют только в текущем процессе и не записываются в настройки, историю или журналы. Незашифрованные промежуточные файлы защищённого экспорта находятся в папке с правами 0700 и удаляются при штатной отмене и ошибках. Публикуются только файлы, прошедшие проверку режима; сбой не приводит к незашифрованной альтернативе.
- Набор OCR-языков определяется локальным Vision; число языков интерфейса не означает такое же число языков OCR.

## Границы проверки

- Проверка выполнена на Intel Mac. Обе архитектуры универсального пакета 1.3 собраны успешно; на реальном Apple Silicon приложение не тестировалось.
- Минимальная целевая система — macOS 14; фактический запуск выполнен на macOS 15.7.9.
- Масштабные измерения производительности на сканированных книгах не проводились. Совместимость со всеми RAW-форматами камер и нестандартными PDF-целями не гарантируется.
- Шифрование использует Apple PDFKit, требует AESV2/128 бит и проверяет пароли и права согласно режиму. Ошибка локального нативного интерфейса при пароле открытия 17–31 символ затрагивает аутентификацию owner. Поэтому в двухпарольном режиме открытие единообразно ограничено 1–16 символами; пароль редактирования и оба однопарольных режима поддерживают 1–32. Приложение самостоятельно не исправляет криптографические результаты. Unicode, управляющие символы и длины за пределами режима отклоняются. Предварительная проверка, права owner и сохранение крайних пробелов подтверждены тестами реальных файлов; в двухпарольном режиме длины открытия 17, 31 и 32 отклоняются до записи.
- Метки страниц с пользовательскими текстовыми префиксами нельзя надёжно сохранить текущим нативным способом; при шифровании выводится явная ошибка. Обычная буквенная, римская и числовая нумерация по разделам, режим чтения и метаданные проверены циклическими тестами. Во встроенном просмотре можно ввести пароль открытия; файл только с паролем редактирования открывается сразу. Редактирование закладок зашифрованных файлов недоступно.
- Отличия от исходной программы, включая кодирование JBIG2/G4, старую проверку OCR, многослойный интерфейс и некоторые специальные цели закладок, описаны в разделе «Явные отличия от исходной программы» README проекта.
